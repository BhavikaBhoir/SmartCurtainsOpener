# Smart Automatic Curtains Opener (Arduino)

An IoT-inspired Arduino project that automates curtain movement using an LDR sensor and servo motors based on ambient light intensity.

## 🧰 Components Used
- Arduino Uno
- LDR (Light Dependent Resistor)
- Servo Motors
- Breadboard
- Jumper Wires

## ⚙️ How It Works
The LDR detects the surrounding light level:
- When light intensity is high → curtains open
- When light intensity is low → curtains close

Servo motors are controlled by the Arduino to perform the curtain movement automatically.
